# Discord appearance

Discord owns its appearance through account settings. Its official desktop
controls are under User Settings → Appearance. Choose Dark for the standing dark
preference when a signed-in session is available. Custom colors require Nitro;
the editor accepts hex colors and a dark base, but is not a complete Cyberdream
palette export. Use scarlet `#FF493D` where supported and verify the result before
claiming a palette match.

On a fresh installation, finish installation and launch verification even if
sign-in prevents access to Appearance. Report the theme limitation. Keep login
state, tokens, and Electron profile data mutable and outside the repository and
Nix store. Manage only documented settings; an app installation does not authorize
adding a modified client or purchasing Nitro.

Source: [Discord's appearance documentation](https://support.discord.com/hc/en-us/articles/207260127-How-to-Change-Discord-Color-Themes-and-Customize-Appearance-Settings)
(checked 2026-10-22).
