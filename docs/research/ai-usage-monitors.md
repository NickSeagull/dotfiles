# AI subscription usage monitors for macOS

Checked: 2026-10-15. Requirement: free, open-source, multiple AI providers, and several distinct ChatGPT subscription accounts retained at once. This is research only; no monitor was installed or authenticated.

**Recommendation: CodexBar.** It combines a broad provider catalog with verified support for multiple Codex/ChatGPT accounts in the released v0.75.0 documentation. It is available as a Homebrew cask and requires macOS 14+. The recommendation is based on documented capabilities, not a hands-on test with the user's accounts. [Project and installation](https://github.com/steipete/CodexBar), [release](https://github.com/steipete/CodexBar/releases/tag/v0.75.0).

**Scope matters:** the confirmed ChatGPT-account integrations below expose **Codex subscription quota and resets**. This review did not verify comprehensive message-limit counters for ordinary ChatGPT conversations, voice, images, or every ChatGPT model. Codex quota, locally estimated token costs, and API billing are separate measurements. CodexBar explicitly documents these coverage differences. [Codex data sources and coverage](https://github.com/steipete/CodexBar/blob/v0.75.0/docs/codex.md).

Table evidence: [CodexBar released account documentation](https://github.com/steipete/CodexBar/blob/v0.75.0/docs/codex.md), [AgentMeter provider matrix](https://github.com/fdtorres1/AgentMeter#providers) and [multi-account guide](https://github.com/fdtorres1/AgentMeter/blob/main/docs/CODEX_ACCOUNTS.md), [Headroom account workflow](https://github.com/MariuszT/headroom-ai#adding-accounts), [Quotio macOS guide](https://github.com/nguyenphutrong/quotio/blob/master/apps/macos/README.md).

For CodexBar, use **Settings → Providers → Codex → Accounts → Add Account** for each login, ensuring the browser selects the intended ChatGPT identity. The managed flow uses Codex login; the shipped documentation includes CLI discovery and troubleshooting. Separate settings rows preserve account-specific usage and timestamps, and refreshing every account does not change the system account. Enable other providers individually. [Released Codex guide](https://github.com/steipete/CodexBar/blob/v0.75.0/docs/codex.md), [documented Add Account flow](https://github.com/steipete/CodexBar/issues/1199).

AgentMeter is the clearest alternative if existing separate Codex homes are preferable: sign into each home, then add it under **Settings → Providers → Codex accounts**. Its live readings come from short calls to the official Codex CLI rather than its own token handling. [Account guide](https://github.com/fdtorres1/AgentMeter/blob/main/docs/CODEX_ACCOUNTS.md).

These remain third-party integrations. Headroom explicitly notes that its direct provider endpoints are unsupported and can change; successful documentation review does not establish future compatibility. No account credentials were accessed for this research. [Headroom limitations](https://github.com/MariuszT/headroom-ai#what-this-is-not).
