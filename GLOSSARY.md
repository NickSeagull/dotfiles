# Personal workstation

Declarative configuration and keyboard workflows for this workstation.

## Language

**Action layer**:
A set of keyboard actions available while an ordinary typing key is held. The held key selects the set; a key pressed with the opposite hand selects an action within it.
_Avoid_: Chord, when referring to the entire layer rather than a specific key combination.

**Home-row modifier**:
A home-row key that types its ordinary character when tapped and acts as a modifier while intentionally held. Matching fingers on the two hands provide the same modifier.

**Emergency disable**:
A keyboard-workflow state in which remapping is off and ordinary typing is restored. It persists until remapping is explicitly enabled again.
